Netdata keeps per-second samples, so a faster poll returns real data. Each poll is a round trip over the WebSocket.

Floor 10s

Ignored below 10s. pvestatd recomputes guest statistics on its own 10s cycle, so polling faster returns the same numbers and only adds load and log lines. A hard property of PVE, not a preference.
